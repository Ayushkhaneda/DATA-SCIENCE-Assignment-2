# DATA-SCIENCE-Assignment-2
Analysis of 3000 movies dataset to identify profit trends, ROI by language, top producers, actor frequency, and director-actor relationships using Python.

# 🎬 Movie Data Analysis

## 📌 Overview
This project analyzes a dataset of 3000 movies to extract meaningful insights about profitability, return on investment (ROI), and industry patterns.

The goal is to understand what makes movies successful and how factors like language, cast, and director influence performance.

---

## 📊 Dataset
- Total Movies: 3000
- Features include:
  - Budget & Revenue
  - Genres
  - Cast & Crew
  - Language
  - Release Date

---

## ⚙️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 🔍 Key Analysis Performed

### 1. Highest Profit Movie
- Identified the movie with maximum profit
- Extracted its director, producers, and main cast

### 2. ROI by Language
- Compared average ROI across different languages
- Identified the most profitable language group

### 3. Genre Exploration
- Extracted all unique movie genres
- Analyzed diversity in the dataset

### 4. Top Producers
- Calculated average ROI for each producer
- Identified top 3 producers based on performance

### 5. Actor Analysis
- Found the most frequent actor
- Analyzed their movies, genres, and profits

### 6. Director-Actor Relationships
- Identified top 3 directors
- Analyzed which actors they collaborate with most

---

## 📈 Key Insights
- High-budget action movies tend to generate the highest profits
- ROI is often skewed by low-budget films with high returns
- Certain actors appear frequently across successful movies
- Directors tend to repeatedly work with the same actors
